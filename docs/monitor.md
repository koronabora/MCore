# Консольный монитор MCore

Запуск из root-shell: `mcore-top` (либо `sudo mcore-top`). Выход — **q** или
**Ctrl+C**, пробел — пауза экрана, **r** — обновить, стрелки — прокрутка пользователей.
Удобный размер терминала: от 120 столбцов и 25 строк; изменение размера поддерживается.

```sh
mcore-top
mcore-top --interval 5
mcore-top --once
mcore-top --json
mcore-top --interface eth0
```

Показывает:
- systemd-состояние MCore, PID, CPU и резидентную память процесса;
- прослушивание API-порта и количество установленных TCP-соединений;
- uptime, load average, CPU/RAM/swap ОС;
- скорость выбранного сетевого интерфейса ОС и физического дискового I/O MCore;
- занятое/свободное место разделов, физический объём видео, данных и резервных копий;
- пользователей, число сохранённых ключей входа и последнее событие:
  отметка просмотра с названием/серией/позицией, поиск или подключение устройства.

**Как читать активность:** это сохранённые события, а не точный список онлайн.
Отметки просмотра приходят от клиента; свежая отметка сама по себе не доказывает,
что видео сейчас воспроизводится (пауза тоже сохраняет позицию). Скачивание без
просмотра не записывается в эту историю. Ключи входа — не активные подключения.
TCP-соединения показываются общим числом, без привязки к пользователю.
Сеть — всего выбранного интерфейса, не только MCore. CPU процесса: 100% = одно ядро.

Состояние обновляется раз в 2 секунды. Каталоги считает отдельный поток не чаще
раза в минуту, через низкоприоритетный `du`, с ограничением в 20 секунд. Данные
могут меняться во время подсчёта. Для sparse-файлов показано реально выделенное
место; настроенный лимит видеокеша относится к логическому объёму. Строки разделов
могут показывать один и тот же диск — их нельзя складывать.

Монитор читает `/proc`, `systemctl show` и SQLite через `mode=ro`/`query_only`.
Не использует конструктор Store, не создаёт пользователей/сессии, не запускает
миграции, не меняет файлы видео. Чтение БД ограничено по времени; при проблемах
отображается ошибка. Ключи доступа, приглашения и серверные секреты не выводятся.
Новые Python-зависимости не требуются (Debian 13, системный Python 3.13).

## Установка на работающий сервер без остановки MCore

Из root-shell:

```sh
install -d -m 0755 /opt/mcore/tools
install -m 0644 /home/kot/MCore/deploy/mcore-top.py /opt/mcore/tools/mcore-top.py
install -m 0755 /home/kot/MCore/deploy/mcore-top /usr/local/sbin/mcore-top
mcore-top --once
```

Это отдельный инструмент. Перезагрузка ОС, `daemon-reload` и перезапуск MCore
не нужны. Общий `deploy/install.sh` для такой установки запускать не следует:
он предназначен для полного развёртывания и перезапускает службы.

Проверено: четыре теста (включая чтение при незавершённой транзакции сервера),
живой текстовый/JSON-снимок и интерактивный терминал с изменением размера и выходом.
При установке и проверке PID и systemd InvocationID MCore остались прежними.
